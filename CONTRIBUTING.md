# Colaborar

El proyecto se distribuye bajo MIT (LICENSE). Se agradecen incidencias y propuestas en https://github.com/JLInF97/menu-compra-ha/issues. No incluyas claves, tokens, copias de datos ni información personal.

Para desarrollar y ejecutar pruebas, consulta PRUEBAS.md. El comportamiento de1.0.0 es la base aceptada; las nuevas funcionalidades se plantean como evolutivos separados. Conserva los datos existentes, la interfaz en castellano, las rutas relativas a Ingress y las protecciones del bridge.

Antes de proponer cambios, ejecuta las pruebas y no afirmes compatibilidad con arquitecturas que no hayas comprobado. GitHub Actions realiza verificaciones locales y de contenedores; no sustituye una prueba completa en Home Assistant.
